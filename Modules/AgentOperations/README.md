# Agent Operations

Reusable public-safe operating guidance for agents coordinating bounded work.

- `subagent_delegation.md` — route deterministic routine work, stop on any
  unexpected outcome, and escalate its evidence for smarter diagnosis.
- `job_journal.md` — keep a long multi-item job resumable: ledger on disk,
  artifacts verified before they count, resume that continues instead of
  restarting.
