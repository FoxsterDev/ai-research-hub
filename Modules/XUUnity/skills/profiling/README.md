# XUUnity Profiling Skills

## Purpose
Use `skills/profiling/` for evidence-based mobile performance work.

## Files

- `android_device_capture.md` — Editor Profiler connected to an Android device from code, frame history, deep-profile builds, SurfaceFlinger pacing, screen recording to judge user-visible freezes.
- `instrumentation.md` — markers and custom samples.
- `regression_detection.md` — before/after comparison.
